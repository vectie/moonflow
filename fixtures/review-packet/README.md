# Pending-review packet protocol fixture

`projection.json` and `history.json` are hand-authored synthetic responses shaped
for the existing native `status` and item-filtered `run-history --json` commands.
They are not generated by native replay and do not qualify the engine, adapter,
health, approval or execution. The test executable only serves these files; it
is not a replacement runtime.

`workspace/outputs/summary.txt` deliberately uses UTF-8 and CRLF. `metrics.json`
is a real JSON file with synthetic measurements; `thumbnail.png` is a tiny binary
PNG for byte-preservation coverage, not an actual rendered prototype. The selected result's recorded
ordered output digest was calculated from their exact bytes and references.
The cumulative artifacts and history also name unavailable old/unrelated files;
they must not be copied as current outputs. The status fixture includes an
unselected item whose criteria must not enter the packet.

Run `python3 -B -m unittest discover -s scripts -p 'test_review_packet.py' -v`
from the repository root. It executes the actual exporter, reopens its ZIP and
checks byte preservation and the reviewer-facing index. For use with a real
configured product, see [review packets](../../docs/REVIEW_PACKETS.md).
